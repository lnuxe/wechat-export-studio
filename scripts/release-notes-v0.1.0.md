把泡菜鱼 skill 的 `wechat-win-export-v4` 导出流程做成可视化桌面应用：

## 这个版本能做什么

- **解密**：实测参数 `page=4096 / reserve=80 / IV@4016 / PBKDF2-HMAC-SHA512×256000`；
  每个库同时跑「只用主库」与「主库 + WAL」两条路径，按 **最新消息时间 → 行数** 择优。
  实测无条件合并 WAL 会倒退 15 小时、少 8867 行，而两者 mtime 完全相同。
- **读会话**：聊天软件式交互——贴底显示、往上滚自动加载更早的消息、来新消息自动跟随；
  「实时」是对已解密库的 1.5 秒短轮询（失焦暂停）。
- **导出**：`chat.txt`（与泡菜鱼 local-chat-pipeline 行格式一致）/ 单文件 HTML 阅读器（可搜索可打印）/
  Markdown / JSON / CSV，另可生成一份泡菜鱼分析提示词。
- **会话画像**：每日与每小时分布、我方占比、中位回复间隔。

## 使用前提（重要）

1. **只处理你本人账号、你自己机器上的本地数据。**
2. 需要先有解密密钥：微信 4.x 的内存里只有 passphrase，`SetDBKey` 只在进程启动时调用一次，
   因此要用 [Ray0612/WeChat-Export-Tool](https://github.com/Ray0612/WeChat-Export-Tool) 的 `wx_key.dll`
   走「关微信 → 由工具拉起微信 → 立即抓取」，拿到 `key.txt`。
   应用会自动在桌面 `wx_export\key.txt` 与工作目录里找它。
3. 解密产物是**明文数据库**，请放在受控目录，不要同步网盘、不要提交仓库。

## 已知限制

- 只有「已同步」的会话才有消息表，部分会话点开会提示找不到（这是数据侧事实，不是 bug）。
- 想看到微信里刚发的消息，需要回「连接」页重新解密一次——应用读的是解密快照。
- 图片/语音/视频只导出占位标记，不含媒体文件本身。
